1.表示回数（IMP）

この節の要点
  • 落札した広告の選定と配信は別の出来事
  • 広告主が観測できるのは左辺だけ
  • 0 か、減ったか
  • serving_issues が空でも表示の約束ではない
  • 表示は中間の指標

1-1.定義と分解式

  • インプレッション数: 回答の下に広告が表示された回数。落札した広告の選定と配信は別の出来事で、ChatGPT が掲載を承認して表示し、配信の確認が取れて初めて配信と扱う ✓（B:基盤）
  • 分解〔推測〕: 表示 ≒ 届く会話のターン数 × 候補に入る率 × 資格を通る率 × オークションで選ばれる率 × 回答に間に合う率。広告主が観測できるのは左辺だけ
  • 広告主が動かせるもの: 予算、期間、地域、端末、オーディエンス、入札戦略と目標、文脈ヒント、広告（タイトル・本文・画像・LP）

1-2.まず切り分ける順番（IMP に特有の点）

  1. 1
    0 か、減ったか

    0 なら §0-4 の 1〜6（止まっている理由がある）。減ったなら 7〜9（細っている）

  2. 2

    0 なら、広告の「配信停止」の理由と API の serving_issues を先に見る。serving_issues が空でも表示の約束ではない ✓（D:Ads）

  3. 3

    減ったなら、プラットフォーム・国の内訳で、どこが減ったかを分ける

  4. 4

    予算（SPD）と一緒に見る。予算を使い切っていれば表示の減少は予算が理由

1-3.「減った・0 のまま」の木（IMP-下）

  • ⓪ 見かけ
    • IMP-下-01 立ち上げから 24 時間たっていない・直近の数字がまだ出そろっていない
    • IMP-下-02 比べる期間が週の境目・時間帯・絞り込みでずれている
  • ① アカウント
    • IMP-下-03 事業者の確認・請求の設定・支払い方法が済んでいない・無効
    • IMP-下-04 アカウントの費用の上限（期間の上限・1 日の上限）を使い切った
    • IMP-下-05 ブランド名を変えてブランド審査待ち・法人名を変えて事業者の審査のやり直し
  • ② キャンペーン
    • IMP-下-06 キャンペーンが一時停止・期間外（開始前・終了後）
    • IMP-下-07 1 日の予算で、週の枠（7 倍）を早く使い切った
    • IMP-下-08 通算の予算で、ペースが先行して配信を緩めた・使い切った
    • IMP-下-09 新しいセルフサーブのアカウントで、自国の外に出そうとしている（自国だけの制限）
  • ③ 広告グループと計測

5.よくある思い込みと実際

思い込み表示が減ったら品質スコアを見る

実際品質スコアに当たる指標は無い。§0-4 の順で止まり方を先に外す

出典: 00§0、02§8

思い込み配信が出ないなら入札を上げる

実際入札を上げても、止まったキャンペーン・使い切った上限・却下は直らない。入札は 5 番目

出典: D:Ads

思い込み低入札の警告が無いから入札は十分

実際変更から 24 時間は出ない。警告が無いことは十分の証拠ではない

出典: D:Ads

思い込みserving_issues が空なら出るはず

実際空でも表示の約束ではない（機会が少ない・狭い・入札が弱い）

出典: D:Ads

思い込み1 日の予算を 1 万円にしたら 1 日 1 万円まで

実際1 日は 2 倍まで使い、週の 7 倍でならす。週の前半で使い切ると後半が止まる

出典: 02§7-2

思い込み費用が 0 円なら課金されていない

実際費用は約 7〜8 時間遅れる

出典: H:20001207

思い込み「学習期間の 7 日」は待つ

実際学習の日数は公式に無い。Google の数字を持ち込まない

出典: 02§9

思い込み文脈ヒントを足せば表示が増える

実際ヒントは完全一致のキーワードではなく、配信を保証しない

出典: H:20001207

思い込み他国を除外すれば日本だけに出る

実際全部の国を選んで一部を除くと、除いていない国に出る。日本を明示して含める
