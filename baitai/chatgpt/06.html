  2. 02

    ピクセルとコンバージョン API を両方使うなら、同じピクセル ID・同じイベント名・同じイベント ID で送る。 重複を除く鍵はこの 3 つ（カスタム イベントはイベント名の代わりに custom_event_name）。先に届いたほうを採り、後から届いたものは捨てる ✓公式本文（S-01 Measurement Pixel・Conversions API）

  3. 03

    oppref が計測の要。 広告のクリックで LP の URL の末尾に付く OpenAI のクリックの参照。ピクセルが拾ってファースト パーティ Cookie __oppref（書き込みから 30 日）に入れる。コンバージョン API は自動で拾わないので、自分で保存して送る。リダイレクトで落とさない ✓公式本文（S-01、S-45 20001409）

  4. 04

    コンバージョン API は「起きてから 7 日以内」の出来事しか受け付けない（未来は 10 分まで）。1 回に 1,000 件まで送れるが、1 件でも不正だと全体が失敗する。イベントの品質の点検は「起きてから 1 時間以内に届いたか」を見る ✓公式本文（S-01 Conversions API、K-01）

  5. 05

    自動詳細マッチング（AAM）は、日本以外では既定でオン、日本の広告アカウントでは広告主がオン・オフを選ぶ。 ピクセルの編集画面で設定する。日本の既定値は書かれていない ? ✓公式本文（S-45 20001409 の英語版・日本語版）

  6. 06
