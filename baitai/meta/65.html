0.先に結論（この章で一番効く 7 点）

  1. 01

    日次の実績を決まった形で取るなら、Marketing API の Insights API（GET /act_<ID>/insights）を、権限 ads_read だけのシステムユーザーのトークンで呼ぶのがいちばん小さい道〔推測。部品はすべて ✓〕。自分の広告アカウントだけなら、ads_read は標準のアクセスで足り、アプリの審査は要らない ✓（A-07）

  2. 02

    公式の Ads MCP サーバー（https://mcp.facebook.com/ads）は日本語の案内があり、追加料金なし。ただしオープンベータで段階的に提供中、「すべての広告アカウントが利用できるわけではない」 ✓（A-03・A-04）。

  3. 03

    MCP は「読むだけ」に絞れる: トークンの権限を ads_mcp_management＋ads_read にする ✓（A-01）。さらに Business Suite の「広告 MCP サーバー」のルールで、エージェントの操作を全部（all）止められる ✓（A-02・A-03）。ただしルールは「限定提供」✓（A-02）

  4. 04
