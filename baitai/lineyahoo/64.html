4.入札戦略

この節の要点
  • 値が消える
  • API で目標値ありのキャンペーンを SET するときは targetCpf を毎回入れ直す
  • 引き上げ 1〜100%・引き下げ −1〜−90%
  • キャンペーンの入札戦略が次のときは適用されない
  • 友だち追加数の最大化（目標値あり／なし）
  • 個別友だち追加単価では調整率が効く

4-1.3 つの戦略 ✓〔仕様〕（F64-02、F63-03 p13、F64-14）

戦略（管理画面）API の値中身設定する値
友だち追加数の最大化（目標値あり）MAXIMIZE_GAINING_FRIENDS＋targetCpf友だち追加単価の目標値を維持しながら、できるだけ多く友だちを獲得するよう入札を自動調整目標友だち追加単価（tCPF）
