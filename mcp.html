運用 MCP を使う

運用 MCP（ochinana_ads）は、このサイトと同じ知識ベースを、Claude などの AI から引けるようにした道具の集まりです。誰でも、自分が運用している広告アカウントを自分の認証でつないで使えます（MIT ライセンス）。AI が実績を読み、判断の型としきい値に当てはめて答えます。広告アカウントは読むだけで、変えるのは人です。

01

しくみ

あなたが AI に聞くと、AI が運用 MCP の道具を呼びます。道具は知識ベースを引き、Google 広告の実績を読んで返します。

04

誰が使えるか・入れ方

  1. 誰でも使えます（MIT ライセンス）。コードは GitHub で公開しています。使う・写す・直す・配ることができます。何も保証はなく、広告アカウントで何をするかは、使う人が決めます。
  2. 自分が運用しているアカウントを、自分の認証でつなぎます。共有のサーバーはありません。使う人がそれぞれ、自分のコンピューターに入れて動かします。
  3. 読むのは、許可リストに入れたアカウントだけです。入れてよいのは、自分が運用を任されていて、持ち主が AI の道具で扱うことを認めたものです。
  4. 要るもの・入れ方の 8 段・つまずいたときは、README にあります。手順はここには書きません（README の方が新しい版です）。

GitHub の README を開く › ライセンスの文

05

使うときの決まり

項目中身
広告アカウント読むだけです。入札・予算・広告を変える呼び出しは、コードのどこにもありません。道具と AI は、点検して案を出すところまでです。変えるのは人で、管理画面で行います。
読めるアカウント自分で決めた許可リストの ID だけです。入れてよいのは、自分が運用を任されていて、持ち主が AI の道具で扱うことを認めたアカウントです。リストに無い ID は、API を呼ぶ前に断ります。
鍵（認証の値）自分の手元のファイルに置きます。道具にはファイルの場所だけを教えます。道具も AI も、鍵の中身を読んだり表示したりしません。認証を取る操作は、AI にさせず自分の端末で行います。
鍵が無いとき知識ベースと計算の道具は動きます。Google 広告を読む道具だけが断ります。
外へ送るものGoogle 広告 API への読み取りの問い合わせ。LP の点検では URL だけを PageSpeed Insights へ。量の見込みでは、キーワード・地域・言語をキーワードプランナーへ。ほかの道具は何も送りません。
金額円のアカウント向けです。円以外のアカウントは、実績を読む道具が断ります。
確かめた範囲テストは本物の API を呼ばず、にせの応答で確かめています。CSV の列の名前は各媒体の公式の説明に合わせていますが、実物の書き出しのファイルでは、まだ全部は試していません。
ライセンスMIT ライセンスです。使う・写す・直す・配ることができます。著作権の表示とライセンスの文は残します。何も保証しません。知識ベースのメモが引いている各社の公式の文は、それぞれの持ち主のものです。
公式かどうかGoogle の公式の道具ではありません。
